Building From Source Code

Instructions for compiling both Desktop (Tauri v2 + Rust) and Mobile (Android Kotlin):

1. Desktop Build (Tauri v2 + React 19 + Rust)

Desktop Setup (Bash / PowerShell) 
# Clone repo and install dependencies
git clone https://github.com/xtros/Muziso.git
cd Muziso
npm install

# Run Desktop app in development mode
npm run tauri dev

# Compile standalone production installers
npx tauri build

2. Android Mobile Build (Native Kotlin + Gradle)

Android Build (JDK 17 + Gradle) 
# Prerequisites: JDK 17+ and Android SDK 34+
cd android
./gradlew assembleDebug

# Generate release APK
./gradlew assembleRelease

Core Commands & Architecture Interfaces

Key interfaces powering Desktop IPC and Mobile Native Services:

💻 Desktop Rust IPC Commands:

IPC Command Arguments Description
init_gstreamer None Initializes GStreamer audio pipeline and dynamic DLL runtime path injection.
resolve_stream_url url: String Invokes sidecar engine to resolve high-bitrate direct audio URLs.
scan_local_directory path: String Recursively parses audio metadata tags using lofty and indexes into SQLite.
update_discord_rpc title: String, artist: String Broadcasts active song title and duration to the local Discord client.

📱 Mobile Android Architecture Components:

Component Layer Description
MuzisoAudioService Foreground Service Manages Jetpack Media3 ExoPlayer lifecycle, notification bar controls, and lockscreen media session.
JioSaavnResolver Repository / Network Direct 320 kbps sub-30ms audio URL resolution using OkHttp.
MuzisoRoomDatabase Persistence (Room) Local Android SQLite database storing offline audio files, history, and playlists.
HeadsetReceiver BroadcastReceiver Handles noisy audio intent (auto-pause on headphone disconnect / resume on Bluetooth).

Muziso Privacy Policy

Effective Date: February 19, 2026 • Covers Desktop & Mobile Editions

🛡️ Privacy Commitment

Muziso ("the Application") is an open-source music player created by Webs By JTS for Desktop and Android Mobile. We respect your privacy and operate under a 100% local, offline-first privacy architecture. Muziso does not collect, track, store, or transmit your personal data, audio files, search queries, or listening habits.

📊 Data Storage & Network Requests

1. 100% Local Database Storage

All playlist entries, liked tracks, offline download indexation, and settings are saved strictly on your local device (Desktop SQLite / Android Room Database). None of this data is uploaded to cloud servers.

2. Streaming & Metadata Resolution

When streaming online tracks, Muziso queries official CDN endpoints (JioSaavn / Spotify Web API). Requests contain strictly anonymous song/artist IDs with zero user identifying cookies or tracking tokens.
