The Next-Gen Modern Desktop Music Player

Muziso brings local audio collections and high-fidelity web streaming into a seamless, high-performance desktop app powered by React 19, Rust, Tauri v2, GStreamer, and SQLite.

Download Desktop App View Setup Guide
⚡

Native Rust Performance

Built on Tauri v2 and native Rust FFI bindings, Muziso uses a fraction of the memory of traditional Electron music apps while maintaining instant response times.

🎧

Hybrid Audio Engine

Play high-bitrate local audio files (.flac, .wav, .mp3, .m4a, .opus) seamlessly alongside online stream extraction using local sidecar processes.

🎨

Modern Dark UI

Signature cyber-minimal dark interface featuring custom Framer Motion page transitions, glowing visualizer overlays, and responsive volume controls.

🛡️

Local Privacy & Offline

Your library remains local. Muziso indexes tracks in a lightweight SQLite database (rusqlite) and stores downloads directly on your file system.

🔍

IP-Bound Stream Resolution

Integrated platform-decoupled yt-dlp sidecar engine to resolve online high-resolution audio streams directly with zero proxy latency.

🔀

Smart Queue & Shuffle

Advanced queue management maintaining deterministic historical back-navigation even when shuffle mode is toggled on and off.

📢

In-App Announcement Feed

Real-time developer update feed with read/unread tracking and remote synchronization directly inside the client interface.

🎮

Discord Rich Presence

Displays currently playing song, artist, duration, and album cover art on your Discord profile automatically.

🎹

Global Hotkeys

Control playback (Play/Pause, Next, Previous) system-wide even when Muziso is minimized or running in the background.

💾

Offline Caching & Downloads

Save streaming audio tracks to your disk for immediate offline playback with custom metadata tag indexing.

Developer Build Prerequisites

To compile Muziso from source code, ensure you have Node.js 18+, Rust toolchain, and GStreamer dependencies installed:

Windows PowerShell (Dependencies) 
choco install gstreamer-runtime gstreamer-devel pkgconfiglite -y
$env:PKG_CONFIG_PATH = "C:\gstreamer\1.0\msvc_x86_64\lib\pkgconfig"
$env:GSTREAMER_1_0_ROOT_X86_64 = "C:\gstreamer\1.0\msvc_x86_64\"
macOS Homebrew 
brew install gstreamer gst-plugins-base gst-plugins-good gst-plugins-bad gst-plugins-ugly pkg-config
Ubuntu / Debian APT 
sudo apt update && sudo apt install -y build-essential pkg-config libasound2-dev libgstreamer1.0-dev libgstreamer-plugins-base1.0-dev libgstreamer-plugins-good1.0-dev gstreamer1.0-plugins-ugly libwebkit2gtk-4.1-dev
Build & Run Development Server 
git clone https://github.com/xtros/Muziso.git
cd Muziso
npm install
npm run tauri dev

System Architecture Overview

Muziso operates on a decoupled client-backend design. The web view (React 19) interacts with the Rust Tauri backend using IPC commands, while audio streaming is managed by native GStreamer FFI and rodio bindings.

SQLite Persistence (rusqlite)

Muziso maintains a local SQLite database (muziso.db) storing user library metadata, play history, playlist items, and offline track indices for instantaneous startup.

Sidecar Process Isolation

Online audio resolution is delegated to platform-specific yt-dlp binaries bundle in src-tauri/bin/, executing under strict sandbox constraints.

Key Tauri IPC Commands

The following Rust IPC functions are exposed to the React frontend via @tauri-apps/api/core:

IPC Command Arguments Description
init_gstreamer None Initializes GStreamer pipeline and injects runtime DLL environment paths on Windows.
resolve_stream_url url: String Invokes yt-dlp sidecar to extract high-bitrate direct audio URLs.
scan_local_directory path: String Recursively parses audio metadata tags using lofty and indexes tracks into SQLite.
update_discord_rpc title: String, artist: String Updates active Discord user status activity card with track details.
